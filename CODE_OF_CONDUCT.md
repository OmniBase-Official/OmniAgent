# Code of conduct

This project is small and technical. We want it to be a place where people can disagree about code without being
unpleasant to each other.

## Expected behaviour

- Be respectful and assume good faith. Criticise code and ideas, not people.
- Give specific, actionable feedback, and accept it the same way.
- Say when you do not know something, and when you were wrong.
- Keep reports and discussions on the project's subject.

## Unacceptable behaviour

- Harassment, insults, threats, or demeaning comments about a person or group.
- Publishing someone's private information, or secrets of any kind.
- Sustained disruption, spam, or pressure to merge a change.
- Anything else that would make a reasonable contributor not want to take part.

## Scope

This applies in the repository's issues, pull requests, discussions and other project spaces, and when someone represents the
project in public.

## Enforcement

The maintainers decide what to do about a report. To report a problem, use GitHub's "Report content" on the comment, issue or
pull request, or contact the maintainers through the repository. Reports are handled privately where GitHub allows it.
Consequences range from a request to stop, to hiding or deleting content, to a temporary or permanent block. Maintainers
act in their own time and on a best-effort basis.
