A grep for `observation`, `bounded`, `truncat`, `footer` over `docs/` finds only the log-persistence rule (contract lines 50 and 103: raw observations are never persisted), which an additive count does not touch.
2. **The real bound is in code, not in a document:** `cap_observation` (`agent.py:423`) cuts any observation over `max_observation_tokens` (600) × 4 = **2,400 characters** and **keeps the head, dropping the tail**. `agent.py:404-415` says why: the summary belongs at the head.
3. **So a footer is allowed but will not survive where it matters.** `list_directory` can return up to 1,000 entries (`sandbox.py:68`); any listing over 2,400 characters loses its last line, i.e. the footer, which is exactly the large directory where a count helps. Put the count in the **header** line (`{shown}: 12 entries (12 .py)`), or accept that the footer is inert once the listing is capped. The error parenthetical is safe: the error is about 400 characters plus the path, far under the cap.
4. **Three constraints on the text, none needing an amendment:** (a) count the entries **actually shown** (post-denial), never the pre-filter list, or the number discloses sealed paths such as `docs/` (the sealed-workspace tests at `tests/test_file_tools.py:448` and `tests/test_eval_workspace.py:244` assert only the names, so they would not notice); (b) the extension summary is built from filenames, which §2 calls untrusted data, so bound the number and the length of extensions shown; (c) keep the empty-directory branch as it is, because `tests/test_file_tools.py:191` asserts the exact string `"empty is empty."`.
5. **Tests that must stay green or be changed on purpose:** `tests/test_file_tools.py:84` asserts a substring of the read_file error, so a parenthetical is safe; the read_file/`cap_observation` invariant (`:378`) skips `Error:` results, so it does not pin the error length. G2e and the system prompt are untouched.
6. **Test quality (Rule 1):** a test that the footer exists proves little. Pin the count against a workspace with a denied entry (it must not count it) and against a directory over 2,400 characters (assert where the count sits). Mutation check: count the unfiltered list, and the first test must go red.
