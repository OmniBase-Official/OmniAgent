Synthetic asset ledgers, written for the evidence-grounding category of the
agentic MVP evaluation. Every identifier, token and state in this directory is
invented and refers to nothing real; no user workspace data is here, and none
may be added.

This directory is the subject of the trials, not their answer key. The task
texts and the rubric live in a module the trial's workspace seals, and the
accepted answers are never written down anywhere: they are derived from these
files when the harness loads.

Do not edit these files. The trial record carries a hash of this directory,
computed over every file's path and text with line endings normalised, so an
edit here changes the hash and voids any run reported against the old one.

This is not eval-fixture/. That directory belongs to the older question bank
and is the subject of a listing question in it; nothing here is shared with
it.
